3. "THINK ABOUT IT" REFLECTION
--------------------------------------------------------------------------------
Insight:
"A program that produces a plausible path is not necessarily correct.
Testing should deliberately include cases in which the expected behaviour is known.
This is an important principle of AI engineering:
    Working output != validated algorithm"

Analysis:
A broken search algorithm (e.g., greedy best-first search, depth-first search, or
an inadmissible A* variant) will frequently output a path that looks valid on a
single test map. Only by testing boundary extremes (trivial 1-step, impossible walls,
competing path lengths) can an engineer mathematically prove that the algorithm
implements true optimal A* search.
