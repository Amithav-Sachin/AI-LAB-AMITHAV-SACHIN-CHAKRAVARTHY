2. DETAILED ANSWERS TO INSPECTION QUESTIONS
--------------------------------------------------------------------------------

(a) What data structure is used for the A* frontier?
    Answer:
    A priority queue implemented as a binary min-heap via Python's standard library
    `heapq` module over a standard Python list. The elements are 4-tuples:
        `(f_score, tie_breaker_counter, state, g_score)`
    where `f_score` is the primary key determining min-extraction priority.

(b) How does the program select the next state to expand?
    Answer:
    Using `heapq.heappop(frontier)`. The min-heap guarantees that the node with the
    lowest evaluation value f(n) = g(n) + h(n) across the entire frontier is
    extracted in O(log N) time. If multiple nodes share identical f-scores, the
    `tie_breaker_counter` breaks ties chronologically (FIFO order).

(c) Where is the heuristic calculated?
    Answer:
    The heuristic is calculated in two places:
    1. Initially for the start node prior to search loop: `start_h = heuristic_fn(start, goal)`.
    2. During neighbor expansion when generating unvisited or improved successor nodes:
       `h = heuristic_fn(neighbor, goal)` right before computing `f_score`.

(d) Does the program explicitly calculate f(n) = g(n) + h(n)?
    Answer:
    YES. On line 184 of `search_agent.py`, the code contains the explicit line:
        `f_score = tentative_g + h`
    where `tentative_g` represents g(n') and `h` represents h(n').

(e) How does the program prevent unnecessary repeated exploration?
    Answer:
    Through two complementary mechanisms:
    1. `closed_set: Set[Coord]`: Records every node that has been popped and expanded.
       If a duplicate node in the frontier is popped whose state is already in `closed_set`,
       it is immediately discarded via `if current in closed_set: continue`.
    2. `g_scores: Dict[Coord, float]`: When considering a neighbor, the program checks:
       `if neighbor not in g_scores or tentative_g < g_scores[neighbor]:`
       This prevents pushing neighbor nodes into the heap unless a strictly cheaper
       path to that state has been discovered.
