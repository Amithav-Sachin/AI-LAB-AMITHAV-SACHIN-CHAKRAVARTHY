2. SYNTHETIC Q-LEARNING UPDATE TESTS
--------------------------------------------------------------------------------
Hand calculations vs. programmatic updates using prescribed baseline values:
    Q(s, a) = 0.4,   alpha = 0.2,   gamma = 0.95

Test Case 1: Non-terminal Transition (r = 1.0, max_{a'} Q(s', a') = 2.0)
- Target:
      y = r + gamma * max_{a'} Q(s', a') = 1.0 + 0.95 * 2.0 = 2.9000
- Updated Q(s, a):
      Q_new = Q + alpha * (y - Q) = 0.4 + 0.2 * (2.9000 - 0.4) = 0.4 + 0.5000 = 0.9000
- Programmatic output: y = 2.9000, Q_new = 0.9000  -->  MATCH (PASS)

Test Case 2: Truly Terminal Transition (r = 5.0, goal reached)
- Target:
      y = r = 5.0000  (continuation value max_{a'} Q(s', a') is suppressed)
- Updated Q(s, a):
      Q_new = Q + alpha * (y - Q) = 0.4 + 0.2 * (5.0000 - 0.4) = 0.4 + 0.9200 = 1.3200
- Programmatic output: y = 5.0000, Q_new = 1.3200  -->  MATCH (PASS)

Test Case 3: Truncation Flag Set (r = 1.0, max_{a'} Q(s', a') = 2.0, truncated = True)
- Target:
      y = r + gamma * max_{a'} Q(s', a') = 1.0 + 0.95 * 2.0 = 2.9000
      (Bootstrapping is maintained because 40-step cutoff is an empirical horizon,
       not an intrinsic task termination)
- Updated Q(s, a):
      Q_new = 0.4 + 0.2 * (2.9000 - 0.4) = 0.9000
- Programmatic output: y = 2.9000, Q_new = 0.9000  -->  MATCH (PASS)

Question: Which case should ignore the next-state value?
Answer:
The TRULY TERMINAL case (Test Case 2) must ignore the next-state value.
In a truly terminal state, the episode has terminated within the MDP; there are no
subsequent actions, transitions, or future rewards to collect, so the discounted
continuation return is identically zero.
In contrast, truncation (Test Case 3) is an artificial timeout imposed by the
experimenter. The environment would continue indefinitely if not stopped, so the
agent must bootstrap from the estimated value of the next state to avoid underestimating
the value of states visited near the horizon.
