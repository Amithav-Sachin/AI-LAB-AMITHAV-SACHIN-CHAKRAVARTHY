QUESTION 1:
What did the XOR experiment demonstrate about the difference between depth and
nonlinearity?

ANSWER:
The XOR experiment demonstrates that depth without nonlinearity adds zero representational
capacity. Mathematically, a sequence of L affine transformations:
    a^(1) = W^(1)*x + b^(1)
    a^(2) = W^(2)*a^(1) + b^(2)
    ...
    z     = W^(L)*a^(L-1) + b^(L)
collapses by matrix multiplication into a single affine transformation:
    z = (W^(L) * W^(L-1) * ... * W^(1)) * x + (bias terms) = W_eff * x + b_eff.
Regardless of how many hidden layers or millions of parameters are stacked, the decision
surface remains a flat hyperplane, which is mathematically incapable of solving linearly
inseparable problems like XOR.
Nonlinearity (via activation functions like Sigmoid, Tanh, or ReLU) is the indispensable
operation that introduces curvature, bending and warping the geometric coordinate space so
that points that were previously inseparable in the input space become linearly separable
in the hidden feature space. In summary: depth provides hierarchical compositional depth,
but nonlinearity provides the expressive power to separate non-trivial decision regions.


QUESTION 2:
In your successful run, what evidence showed that backpropagation supplied a useful
learning signal rather than merely a nonzero gradient?

ANSWER:
A nonzero gradient merely indicates that the objective function has local slope; on its
own, a nonzero gradient can produce oscillations, chaotic divergence, or drift into poor
local extrema. In our successful baseline run, conclusive evidence that backpropagation
supplied a purposeful, constructive learning signal includes:
1. Systematic, Monotonic Loss Reduction:
   The Binary Cross-Entropy loss decreased smoothly and continuously over 3000 epochs,
   dropping monotonically from an untrained loss of 0.748230 to 0.000340 (a reduction of
   over 3 orders of magnitude).
2. Convergence to Ground-Truth Discrete Accuracy:
   The thresholded predictions evolved from chance-level outputs to 100% classification
   accuracy (4/4 correct), with probabilities approaching asymptotic certainty
   (0.0003 for class 0; 0.9996 for class 1).
3. Smooth Vanishing Gradient Norm:
   The first-layer Frobenius gradient norm ||grad_{W^(1)} L||_2 was active early in
   training (0.011894) and decayed smoothly to 8.98e-06 at the optimum, confirming that
   the parameter updates were guided directly into a true stationary point.


QUESTION 3:
Why did identical/zero weight initialisation prevent the two hidden units from learning
distinct features?

ANSWER:
Zero weight initialization causes complete symmetry collapse due to the mathematical
properties of the feedforward and backpropagation equations:
1. Identical Forward Activations:
   When W^(1) = 0 and b^(1) = 0, both hidden neurons compute identical pre-activations
   a_1^(1) = a_2^(1) = 0 for every input x in X. Consequently, their activations are
   identical: h_1 = h_2 = sigma(0) = 0.5.
2. Identical Backpropagated Gradients:
   The output weights are also initialized to zero: W^(2) = [0, 0]. The error signal
   backpropagated to each hidden unit is:
       dL / dh_j = (dL / dz) * W_j^(2) = 0.
   Even when W^(2) updates, both components receive identical gradients because h_1 = h_2,
   so W_1^(2) = W_2^(2) holds for all steps.
3. Identical First-Layer Weight Updates:
   By the chain rule:
       dL / dW_{1j}^(1) = (dL / dz) * W_1^(2) * sigma'(0) * x_j
       dL / dW_{2j}^(1) = (dL / dz) * W_2^(2) * sigma'(0) * x_j.
   Because W_1^(2) == W_2^(2), both rows of W^(1) receive identical updates at every step.
   The two hidden neurons remain exact clones of each other, collapsing the effective
   representational rank of the hidden layer from 2 to 1. Because a 2-1-1 network cannot
   solve XOR, the model remains permanently trapped at loss ln(2) ~= 0.693147.


QUESTION 4:
How did changing the hidden activation affect the gradient you observed? Distinguish the
scientific explanation from the engineering observation.

ANSWER:
1. Scientific Explanation (Mathematical Mechanism):
   By reverse-mode automatic differentiation, the gradient of the loss with respect to the
   first-layer weights is given by:
       grad_{W^(1)} L = (grad_h L * f'(a^(1))) (x)^T.
   The choice of activation function directly governs the Jacobian multiplier f'(a^(1)):
   - Sigmoid: f'(z) = sigma(z)*(1 - sigma(z)) is strictly bounded in (0, 0.25]. In every
     layer, the backpropagated gradient is attenuated by at least a factor of 4.
   - Tanh: f'(z) = 1 - tanh^2(z) has a maximum of 1.0 at z = 0 and is zero-centered,
     transmitting stronger gradients without premature attenuation.
   - ReLU: f'(z) = 1 for z > 0 and 0 for z < 0. For active neurons, gradients pass with
     zero attenuation (multiplier 1.0).
2. Engineering Observation (Empirical Measurements at Step 10, seed = 2):
   - Early gradient norm for Sigmoid was 0.008495 (smallest, reflecting the <= 0.25 bound).
   - Early gradient norm for Tanh was 0.046584 (strongest gradient flow).
   - Early gradient norm for ReLU was 0.024614 (active, unattenuated transmission).
   Consequently, ReLU and Tanh descended rapidly, achieving final losses of 4.91e-05 and
   1.32e-04 respectively, whereas Sigmoid converged more slowly to 3.80e-04.


QUESTION 5:
Why must the output layer and loss be selected together according to the task?

ANSWER:
In probabilistic machine learning, the output activation and the loss function are
intimately coupled through maximum likelihood estimation (MLE) of the task distribution:
1. Binary Classification (Task: Bernoulli trial):
   The output is a single probability p in (0, 1), naturally modeled by a Sigmoid activation.
   The MLE objective is the negative log-likelihood of a Bernoulli variable, which is
   Binary Cross-Entropy (BCE).
2. Multiclass Classification (Task: Categorical choice over K mutually exclusive classes):
   The outputs must form a valid probability simplex (sum p_k = 1, p_k >= 0), modeled by
   Softmax. The MLE objective is Categorical Cross-Entropy.
3. The Canonical Link Property:
   When an activation is paired with its canonical loss, the complicated derivative of the
   activation function algebraically cancels the denominator of the loss derivative:
       dL / dz = p - y.
   This yields a linear, stable, and intuitive gradient signal.
If an inappropriate pairing is chosen (such as pairing a Sigmoid output with Mean Squared
Error), the logit gradient becomes:
    dL / dz = (p - y) * sigma'(z) = (p - y) * p * (1 - p).
When the model is confidently wrong (e.g. y = 1 but p ~= 0), the factor p*(1-p) approaches 0,
causing the gradient to vanish precisely when the model needs the largest correction!


QUESTION 6:
Give one example where the LLM improved your engineering productivity and one example
where human verification was essential.

ANSWER:
1. Productivity Improvement:
   The LLM instantly generated clean, syntactically correct PyTorch boilerplate code,
   including dataset tensor creation, network class structure with `nn.Module`, the training
   loop skeleton with `optimizer.zero_grad()`, `loss.backward()`, and evaluation metrics.
   This converted a conceptual mathematical model into working code in seconds.
2. Essential Human Verification:
   The initial raw LLM code suggested using an explicit `nn.Sigmoid()` layer followed by
   `nn.BCELoss()`. Human verification identified that evaluating `ln(sigma(z))` directly
   in 32-bit floating-point causes catastrophic underflow to -inf or NaN when logits are
   moderately large (|z| > 15). Human engineering expertise intervened to replace this with
   `nn.BCEWithLogitsLoss()`, which applies the numerically stable Log-Sum-Exp formulation:
       L = max(z, 0) - z*y + ln(1 + exp(-|z|)).


QUESTION 7:
Which tests in this laboratory would you keep if the model were scaled up, and which
would become too expensive?

ANSWER:
1. Tests to Keep at Scale (Production LLMs / Deep Networks):
   - Tracking scalar loss curves across training steps (detecting divergence, spikes, or plateaus).
   - Monitoring layer-wise Frobenius gradient norms ||grad_W L||_2 (detecting vanishing or exploding gradients).
   - Sanity checks on mini-batch probability distributions (e.g. verifying that softmax components sum to 1.0).
   - Targeted unit tests on small, reproducible synthetic batches to verify symmetry breaking and architecture sanity.
2. Tests That Become Prohibitively Expensive at Scale:
   - Full-Batch Optimization: Training on full datasets is intractable for large corpora; mini-batch SGD is required.
   - Exhaustive Finite-Difference Gradient Checking: Computing (L(w + eps) - L(w)) / eps for each parameter requires
     2 * P forward passes; for a 70-billion parameter model, this requires 140 billion forward passes per step!
   - 2D Dense Grid Decision Boundary Plotting: High-dimensional latent manifolds cannot be densely sampled across a 2D grid.
   - Exact Hessian / Jacobian Spectrum Analysis: Storing and inverting the full parameter Hessian matrix requires O(P^2)
     memory, which is impossible for models with millions/billions of weights.
