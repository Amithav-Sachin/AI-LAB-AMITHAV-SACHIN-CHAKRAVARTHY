2. CODE INSPECTION BEFORE EXECUTION
--------------------------------------------------------------------------------
Before executing the code, we systematically inspect its computational graph:
1. Where the Forward Pass Occurs:
   Inside the `forward(self, x)` method:
       h = self.act(self.fc1(x))
       logit = self.fc2(h)
   The input tensor X passes sequentially through affine map fc1, activation act,
   and output affine map fc2.
2. Where the Scalar Loss is Formed:
   In the training loop:
       loss = criterion(logits, y)
   where criterion is `nn.BCEWithLogitsLoss()`. It computes the element-wise
   logistic loss for each of the 4 examples and reduces them by arithmetic mean.
3. Where Reverse-Mode AD is Invoked:
   At `loss.backward()`. PyTorch executes backpropagation through the reverse
   dynamic computational graph, computing vector-Jacobian products from the
   scalar loss back to each parameter and populating `param.grad`.
4. Where the Optimizer Changes Parameters:
   At `optimizer.step()`. The optimizer updates each parameter tensor along its
   negative gradient direction using the Adam / SGD update rule.


3. TWO ENGINEERING CHANGES MADE BEFORE EXECUTION
--------------------------------------------------------------------------------
Change 1: Replaced `nn.Sigmoid()` + `nn.BCELoss()` with `nn.BCEWithLogitsLoss()`.
  Rationale: The raw LLM boilerplate occasionally outputs `probs = torch.sigmoid(logits)`
  followed by `nn.BCELoss()`. In finite-precision floating-point arithmetic, evaluating
  `ln(probs)` when probs rounds to 0.0 or 1.0 causes underflow to -inf or NaN.
  `BCEWithLogitsLoss` combines the sigmoid and BCE into a single numerically stable
  Log-Sum-Exp formulation: max(z, 0) - z*y + ln(1 + exp(-|z|)).

Change 2: Explicit Gradient Zeroing and Tracking of Initial Loss.
  Rationale: We ensured that `optimizer.zero_grad()` is called strictly before
  `loss.backward()` inside every epoch so gradients do not accumulate across
  full-batch iterations. In addition, we inserted an initial evaluation pass before
  the training loop to record the untrained initial loss and initial gradient norm
  as required by the laboratory checkpoint.
