2. GEOMETRIC SKETCH & LINEAR INSEPARABILITY
--------------------------------------------------------------------------------
Coordinate Representation in the (x1, x2) plane:

       x2
        ^
    1.0 |    (0, 1) [Class 1] --------- (1, 1) [Class 0]
        |          \                      /
        |           \                    /
        |            \      (0.5, 0.5)  /
        |             \        [X]     /
        |              \              /
    0.0 |    (0, 0) [Class 0] --------- (1, 0) [Class 1]
        +---------------------------------------------> x1
       0.0                         1.0

Why One Straight Decision Boundary Cannot Separate the Two Classes:
A straight decision boundary in R^2 is defined by the affine hyperplane:
    H = { (x1, x2) in R^2 : w1*x1 + w2*x2 + b = 0 }
The points of Class 1 ((0, 1) and (1, 0)) lie on the anti-diagonal, whose convex
hull is:
    conv(C1) = { (lambda, 1 - lambda) : lambda in [0, 1] }
The points of Class 0 ((0, 0) and (1, 1)) lie on the main diagonal, whose convex
hull is:
    conv(C0) = { (mu, mu) : mu in [0, 1] }

The two convex hulls intersect at lambda = 0.5, mu = 0.5 -> (0.5, 0.5).
By Radon's Theorem and the Hyperplane Separation Theorem, two sets in R^d can be
strictly separated by an affine hyperplane if and only if their convex hulls are
disjoint:
    conv(C0) intersect conv(C1) = {(0.5, 0.5)} != empty_set
Therefore, no single straight line in R^2 can separate the two classes without
at least one classification error. XOR is fundamentally linearly inseparable.

--------------------------------------------------------------------------------
Architecture: y_hat = sigma(w1*x1 + w2*x2 + b)
Decision rule: y_pred = 1 if y_hat >= 0.5 <=> w1*x1 + w2*x2 + b >= 0.

Prediction:
Because the decision boundary is strictly linear, the single affine model cannot
separate the 4 points. When trained using binary cross-entropy, the optimization

Answer:

1. Representational capacity is determined by nonlinearity and geometric folding,

   decision surface remains a rigid, flat hyperplane.
3. Therefore, solving XOR tests whether an architecture possesses the capacity
